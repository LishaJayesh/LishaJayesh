## 🚀 Featured Projects

### 🏦 Banking Customer Support AI Agent
> **Multi-Agent System · LangGraph · GPT-4o · LangChain · SQLite · Streamlit**

A fully autonomous customer support system that handles ticket triage, routing, and response — without human intervention for routine interactions.

- 🤖 **4 specialist agents** orchestrated via LangGraph StateGraph (Classifier → Feedback/Query handlers)
- ✅ **100% automated classification** of messages into Positive Feedback, Negative Feedback, or Query
- 🧠 **LLM-driven flow control** — prompt-based reasoning over full chat history (no boolean flags)
- 🗄️ **Live SQLite integration** — ticket creation, lookup, escalation detection & LLMOps logging
- 💬 **Multi-turn memory** via LangGraph MemorySaver; quality-scored on Empathy, Accuracy & Clarity

### 📰 NewsGenie — AI-Powered News Agent
> **Agentic AI · LangGraph · GPT-4o-mini · NewsAPI · Tavily · Streamlit**

A conversational news assistant that routes queries intelligently, filters misinformation using LLM credibility scoring, and never goes down — even when external APIs fail.

- 🔀 **LangGraph StateGraph** routing: real-time news retrieval vs. LLM general-knowledge response
- 🛡️ **LLM credibility filtering** on 4 signals: tone · source attribution · claim specificity · headline integrity
- 🔁 **3-level fallback chain**: NewsAPI → Tavily web search → LLM-only
- 🗂️ Session-aware chat with transparent credibility labelling on every article card
